# 3634. Minimum Removals to Balance Array

**Date:** February 6, 2026
**Difficulty:** Medium

## Problem Description
You are given an array of integers `nums` and an integer `k`. A subset of `nums` is **balanced** if the maximum element of this subset is less than or equal to `k` times the minimum element.
Return the minimum number of elements to remove from `nums` to make the remaining array balanced.

## Solution

```cpp
class Solution {
public:
    int minRemoval(vector<int>& nums, int k) {
        int n = nums.size();
        sort(nums.begin(), nums.end());
        int l = 1;
        int maxel = nums[0];
        int minel = nums[0];
        int i = 0;
        int j = 0;
        while (j < n) {
            minel = nums[i];
            maxel = nums[j];
            while(i<j && maxel > (long long)minel * k){
                i++;
                minel = nums[i];
            }
            l = max(l , j-i+1);
            j++;
        }
        return n-l;
    }
};
```

## Complexity Analysis
- **Time Complexity:** O(N log N)
- **Space Complexity:** O(1)
